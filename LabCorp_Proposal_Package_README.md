## ❓ **Frequently Asked Questions**

### **"Can we test one audience first?"**
**Answer:** Yes, but we recommend testing 3-5 audiences to gather comparative data and identify winners faster. A $50K pilot allows for meaningful testing across multiple segments.

### **"How long until we see results?"**
**Answer:** First data within 24 hours. Meaningful optimization insights within 2 weeks. Clear performance trends within 4-6 weeks.

### **"Can we pause anytime?"**
**Answer:** Yes, campaigns can be paused or stopped at any time. We recommend running for at least 30 days to gather sufficient optimization data.

### **"What creative do we need?"**
**Answer:** Standard display ads (static or HTML5). We can provide creative specifications and best practices. Many clients start with existing assets and refine based on performance.

### **"How do we measure offline conversions?"**
**Answer:** Phone call tracking, unique promo codes, location-specific landing pages, or appointment scheduling system integration.
