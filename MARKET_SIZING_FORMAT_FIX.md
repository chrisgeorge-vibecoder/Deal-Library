# Market Sizing Response Format Fix

## Issue Description

Users were seeing raw JSON data displayed in the chat interface instead of properly formatted market sizing responses. The response would show the entire JSON structure including `marketSizing`, `aiResponse`, and `strategicRecommendations` fields as plain text instead of rendering the data in a user-friendly format.

### Example of the Problem

```
{
  "marketSizing": [
    {
      "id": "dog-adopter-market-annual-spend",
      "marketName": "US Dog Adopter Market (Annual Spending)",
      ...
    }
  ],
  "aiResponse": "As the CMO of Chewy...",
  "strategicRecommendations": {
    ...
  }
}
```

## Root Cause

The issue was caused by Gemini AI returning responses in formats that weren't being properly parsed:

1. **Inconsistent Response Format**: Sometimes Gemini would return JSON wrapped in code blocks, sometimes as plain text, and sometimes the `aiResponse` field itself would contain JSON instead of natural language text.

2. **Insufficient Error Handling**: The parsing logic didn't have adequate fallbacks to handle malformed responses, so when parsing failed, it would return the entire raw response as the `aiResponse` text field.

3. **Ambiguous Prompt Instructions**: The prompt to Gemini wasn't explicit enough about the expected format for the `aiResponse` field.

## Solution Implemented

### 1. Enhanced JSON Parsing Logic (`geminiService.ts`)

Added multiple layers of validation and error handling:

```typescript
// Validate that we got proper market sizing data
if (!parsed || typeof parsed !== 'object') {
  throw new Error('Parsed response is not a valid object');
}

// Check if the aiResponse field contains JSON instead of text
if (parsed.aiResponse && typeof parsed.aiResponse === 'string') {
  const aiResponseTrimmed = parsed.aiResponse.trim();
  if (aiResponseTrimmed.startsWith('{') || aiResponseTrimmed.startsWith('[')) {
    console.warn('⚠️ aiResponse appears to contain JSON instead of text');
    parsed.aiResponse = 'Here is the market sizing analysis based on your query.';
  }
}
```

### 2. Improved Fallback Handling

Added logic to detect when the entire response is JSON and handle it appropriately:

```typescript
// Check if the entire response looks like JSON
const trimmedResponse = responseText.trim();
if (trimmedResponse.startsWith('{') && trimmedResponse.endsWith('}')) {
  try {
    parsed = JSON.parse(trimmedResponse);
    // Successfully parsed, continue with the normal flow
  } catch (directParseError) {
    return {
      marketSizing: [],
      aiResponse: "I encountered an error generating market sizing data. Please try again."
    };
  }
}
```

### 3. Explicit Prompt Instructions

Updated the Gemini prompt to be more explicit about the expected format:

```
RESPONSE FORMAT REQUIREMENTS:
- Return ONLY valid JSON, nothing else
- Do NOT include any text before or after the JSON
- Do NOT wrap the JSON in code blocks or markdown
- The "aiResponse" field MUST contain a natural language paragraph (NOT JSON, NOT a data structure)
- The "aiResponse" should be 2-3 sentences summarizing the key insights for a CMO or marketing executive
```
